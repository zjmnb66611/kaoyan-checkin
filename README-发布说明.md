# 考研打卡网站发布说明

## 发布方式

这是一个纯静态网站。将 `index.html`、`js` 目录和 `assets` 目录完整上传到支持 HTTPS 的静态托管服务即可发布，例如 GitHub Pages、Netlify 或对象存储静态网站。

发布包已内置由 Tailwind CSS 3.4.17 生成的静态样式与 Font Awesome 4.7.0 资源，不依赖第三方 CDN。请保持目录结构不变，避免页面样式或图标加载失败。

## 数据与账号

当前发布包使用浏览器本地存储保存打卡数据，不会收集、保存或传输账号密码。云端账号和跨设备同步必须在接入真实后端后再启用，并由后端负责身份认证、权限隔离和数据备份。

发布时不要把数据库管理员密钥、服务端密钥或其他私密配置写入前端文件。若接入 Supabase、Firebase 或自建 API，应仅公开该服务允许暴露的客户端配置，并在服务端启用逐用户的数据访问规则。

## 上线检查

- 使用 HTTPS 域名发布。
- 将压缩包内所有文件按原目录结构上传，不要只上传 `index.html`。
- 验证手机和电脑均能正常打开首页、日历、复盘和设置。
- 确认浏览器刷新后本地任务仍存在。
- 接入云端服务后，单独完成登录、跨设备同步、权限和数据备份测试。
