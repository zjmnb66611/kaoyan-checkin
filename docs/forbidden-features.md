## 二、易混淆边界（合法功能≠禁令功能）

以下功能虽然接近禁令边界，但**明确属于合法范围**：

| 功能 | 与禁令的区分 | 审查要点 |
|------|-------------|----------|
| 打卡备注 | 非独立错题本，仅字段级 | 不可发展为结构化错题数据库 |
| 单科复习进度 | 非学习时长统计，仅完成率 | 不可统计分钟数，仅统计任务完成比例 |
| 科目管理 | 非教学内容，仅分类标签 | 不可关联知识点/题库 |
| 倒计时 | 非番茄钟/计时器 | 仅展示距考研日期的天数 |
| 断卡预警提醒 | 非学习时长追踪 | 仅基于打卡状态（有/无），不基于时长 |

## 四、审查流程

1. **阶段完成时**：开发者自查，勾选审查表
2. **发现渗入**：立即回滚相关代码/设计，更新本文件
3. **模糊边界**：提交到 open-questions.md 待客户确认

---

## 五、处罚规则

- 任何一步发现禁令功能渗入 → 该步重做
- 连续两步发现 → 回退两步重做
- 发现代码中实现了禁令功能 → 删除相关代码 + 阶段重做
