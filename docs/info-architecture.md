## 三、数据流图

### 3.1 整体数据流

```
用户操作
    │
    ▼
┌──────────────┐     ┌──────────────┐
│  状态管理     │────▶│  UI 渲染层    │
│  (State.js)  │     │  (各视图)     │
└──────┬───────┘     └──────────────┘
       │
       ├──▶ LocalStorage (实时写入)
       │
       ├──▶ IndexedDB (大批量数据)
       │
       └──▶ 云端存储 (异步同步)
              │
              ▼
         Supabase DB
```

### 3.2 任务创建流程

```
用户输入任务 → 校验 → 生成 taskId + ISO timestamp
    → 写入 State
    → 写入 LocalStorage
    → 异步: 写入 IndexedDB
    → 异步: 上传云端(登录后)
    → UI 重新渲染任务列表
```

### 3.3 打卡流程

```
用户勾选任务 → 更新任务 status=completed + updatedAt
    → 可选: 添加打卡备注
    → 检查当日任务是否全部完成
        → 是: 触发激励弹窗
    → 更新打卡天数统计
    → 持久化存储
    → UI 更新(含打勾动画)
```

### 3.4 休息日/请假顺延流程

```
用户设定休息日/请假
    → 计算受影响的日期区间
    → 遍历受影响日期的所有任务
        → 将任务 scheduledDate 后移至下一个工作日
    → 同时影响周期性任务生成日期
    → 持久化更新
    → 日历重新渲染(颜色标识)
```

### 3.5 数据同步流程

```
应用启动
    → 检查登录状态
    → 登录: 拉取云端数据
        → 合并本地+云端 (以 updatedAt 为准)
        → 更新本地存储
    → 未登录: 仅读本地存储
    → 渲染 UI

运行时数据变更
    → 本地实时写入
    → 已登录+有网络: 异步上传云端
    → 未登录/无网络: 标记为待同步
```
