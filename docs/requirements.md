# 考研打卡网站 — 功能需求清单

> 本文档基于客户原始需求 PDF 提炼，覆盖全部 8 页需求，无删减，无添加。

## 一、任务管理模块

### 1.1 任务创建
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-01 | 手动新增任务 | 逐个新增任务，包含科目、日期、内容 | P0 |
| T-02 | 批量导入任务 | 按格式批量导入日期+科目+任务数据 | P1 |

### 1.2 单任务操作
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-03 | 修改任务内容 | 编辑已有任务的文字内容 | P0 |
| T-04 | 迁移任务日期 | 将任务从当前日期移动到另一日期 | P0 |
| T-05 | 删除单个任务 | 软删除或确认后删除 | P0 |

### 1.3 未完成任务规则
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-06 | 自动顺延规则 | 当日未完成任务默认自动顺延至次日 | P0 |
| T-07 | 顺延开关 | 提供开关手动开启/关闭顺延规则 | P0 |

### 1.4 批量编辑
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-08 | 批量删除 | 勾选多个任务后批量删除 | P1 |
| T-09 | 批量标记完成 | 勾选多个任务后批量标记为完成 | P1 |
| T-10 | 批量迁移日期 | 批量将选中任务移至指定日期 | P1 |
| T-11 | 批量修改科目 | 批量将选中任务改为指定科目 | P1 |

### 1.5 周期性重复任务
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-12 | 每日重复 | 设置每日自动生成相同任务 | P0 |
| T-13 | 每周固定日期重复 | 可选周一至周日多选，按周循环生成 | P0 |
| T-14 | 自动生成后续任务 | 配置完成后系统自动生成后续周期任务 | P0 |

### 1.6 休息日设置
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-15 | 周期性周休息日 | 多选周一至周日，按周循环生效 | P0 |
| T-16 | 自定义临时休息日 | 支持单日/连续多日临时休息日 | P0 |
| T-17 | 休息日规则 | 当日不生成、不加载任务；原定任务整体后移 | P0 |
| T-18 | 批量新增休息日 | 批量新增非连续休息日期 | P1 |
| T-19 | 取消休息日 | 支持批量取消；周期周休息日可随时开启/关闭/修改 | P1 |
| T-20 | 后期任务顺延 | 休息日后所有周期任务+既定计划同步依次后移 | P0 |

### 1.7 请假功能
| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| T-21 | 请假日期选择 | 支持起止日期（单日/连续多天） | P0 |
| T-22 | 请假期间规则 | 当日无任务；原定任务全部顺延至假期结束次日 | P0 |
| T-23 | 后续顺延 | 请假后所有计划、周期性任务整体依次顺延 | P0 |
| T-24 | 日历颜色区分 | 日历中休息日、请假日期使用不同颜色标识 | P1 |
| T-25 | 撤销请假 | 提供二选一：①保持顺延状态 ②还原至原始日期 | P0 |

### 1.8 逻辑约束（重要）
- 休息日/请假主动顺延规则优先级 **高于** 未完成任务自动顺延开关
- 主动休假顺延与未完成任务被动顺延 **相互独立**
- 周期性周休息日 = **长期循环生效**；临时休息日/请假 = **单次生效**

## 二、打卡功能模块

| 编号 | 功能 | 详细说明 | 优先级 |
|------|------|----------|--------|
| C-01 | 勾选打卡 | 任务支持完成/未完成勾选，可添加打卡备注 | P0 |
| C-02 | 补卡机制 | 支持历史日期补卡，每周最多 1 次补卡机会 | P0 |
| C-03 | 激励弹窗 | 当日全部任务完成后弹出考研励志弹窗 | P1 |
| C-04 | 打卡备注聚合 | 周复盘/月度复盘汇总全部打卡备注 | P1 |
| C-05 | 断卡预警 | 每日 22:00 后若当日无打卡记录，弹出温和提醒 | P1 |
| C-06 | 预警豁免规则 | 休息日、请假日期不触发断卡预警 | P1 |
